# Dividend Alert

เว็บแอปสำหรับติดตามวันขึ้นเครื่องหมาย XD วันจ่ายเงินปันผล และจำนวนเงินปันผลต่อหุ้นของหุ้นใน Watchlist พร้อมระบบแจ้งเตือนผ่าน **ntfy** ล่วงหน้า 1 วันก่อนวัน XD

## 1. เว็บแอปทำอะไรได้บ้าง

- แสดงรายชื่อหุ้นใน Watchlist
- แสดงวันขึ้น XD วันจ่ายปันผล และจำนวนเงินปันผลต่อหุ้น เมื่อมีข้อมูล
- เรียงลำดับตามวัน XD ที่ใกล้ที่สุด หรือเรียงตามชื่อหุ้น A–Z
- เพิ่มและลบหุ้นจากหน้าเว็บได้ โดยบันทึกรายชื่อกลับไปยัง GitHub
- คลิกชื่อหุ้นเพื่อเปิดหน้าเว็บประวัติปันผลย้อนหลัง
- แจ้งเตือนผ่าน ntfy เมื่อหุ้นใน Watchlist มีกำหนด XD ในวันถัดไป

ตลาดที่รองรับในเวอร์ชันปัจจุบัน:

- **TH:** หุ้นไทย เช่น ADVANC, PTT, AOT
- **US:** หุ้นสหรัฐฯ เช่น AAPL, NVDA, TSM

การรองรับตลาดอื่น เช่น จีน ฮ่องกง หรือญี่ปุ่น ยังไม่ได้เปิดใช้งานในระบบเวอร์ชันนี้

## 2. วิธีใช้งานครั้งแรก

### 2.1 เปิดเว็บแอป

เปิดเว็บแอปผ่าน GitHub Pages ได้จากลิงก์ของโปรเจกต์ โดยสามารถเปิดจากคอมพิวเตอร์ แท็บเล็ต หรือโทรศัพท์ได้

การเปิดดูข้อมูล Watchlist ไม่จำเป็นต้องเชื่อมต่อ GitHub Token เพราะหน้าเว็บอ่านข้อมูลที่เผยแพร่ไว้ใน Repository

### 2.2 เชื่อมต่อ GitHub เพื่อแก้ไข Watchlist

หากต้องการเพิ่มหรือลบหุ้น ให้เลื่อนลงไปด้านล่างของหน้าเว็บที่ส่วน **เชื่อมต่อเพื่อแก้ไข Watchlist**

การเชื่อมต่อต้องใช้ **Fine-grained Personal Access Token** ของ GitHub ซึ่งกำหนดสิทธิ์ให้เฉพาะ Repository นี้ และให้สิทธิ์ดังนี้:

- Repository access: เลือกเฉพาะ `dividend-alert`
- Repository permissions: `Contents` เป็น `Read and write`

วิธีสร้าง Token โดยทั่วไป:

1. เข้าสู่ GitHub แล้วไปที่ Settings
2. เปิด Developer settings
3. เลือก Personal access tokens แล้วเลือก Fine-grained tokens
4. สร้าง Token ใหม่ ตั้งชื่อและวันหมดอายุตามต้องการ
5. เลือกสิทธิ์เข้าถึงเฉพาะ Repository `dividend-alert`
6. ตั้ง Repository permissions ในหัวข้อ Contents เป็น Read and write
7. สร้าง Token แล้วคัดลอก Token มาใส่ในช่อง Fine-grained GitHub Token บนหน้าเว็บ
8. กด **เชื่อมต่อ**

เมื่อเชื่อมต่อสำเร็จ จะสามารถเพิ่มและลบหุ้นได้

**ข้อควรระวังเกี่ยวกับ Token**

- Token เปรียบเสมือนกุญแจที่อนุญาตให้หน้าเว็บแก้ไขไฟล์ Watchlist ใน Repository ได้
- หน้าเว็บเก็บ Token ไว้ใน Local Storage ของเบราว์เซอร์บนอุปกรณ์นั้น ไม่ได้บันทึก Token ลงในไฟล์ Watchlist หรือส่งไปเก็บใน Repository
- อย่าเปิดเผย Token ให้ผู้อื่น และไม่ควรเชื่อมต่อบนคอมพิวเตอร์สาธารณะหรืออุปกรณ์ที่ผู้อื่นใช้ร่วมกัน
- เมื่อ Token หมดอายุหรือถูกเพิกถอน จะต้องสร้าง Token ใหม่แล้วเชื่อมต่ออีกครั้ง
- ปุ่ม **ออกจากระบบ** จะมีหน้าต่างยืนยันก่อนล้าง Token ที่บันทึกไว้ในเบราว์เซอร์นั้น การออกจากระบบไม่ได้เพิกถอน Token ที่ GitHub หากต้องการยกเลิกสิทธิ์ Token จริง ๆ ต้องไปเพิกถอนที่ GitHub ด้วยตนเอง

## 3. วิธีเพิ่มและลบหุ้น

### 3.1 เพิ่มหุ้น

1. ตรวจสอบก่อนว่าได้เชื่อมต่อ GitHub แล้ว
2. พิมพ์ Ticker ของหุ้นในช่อง เช่น `ADVANC`, `PTT`, `AAPL` หรือ `NVDA`
3. เลือกตลาดให้ตรงกับหุ้น: หุ้นไทย หรือ สหรัฐฯ
4. กด **+ เพิ่มหุ้น**

ระบบจะตรวจสอบรูปแบบ Ticker และป้องกันการเพิ่ม Ticker ซ้ำในตลาดเดียวกัน

ตัวอย่างเช่น หากมี `US:TSM` อยู่แล้ว จะไม่สามารถเพิ่ม `US:TSM` ซ้ำได้ แต่ระบบพิจารณาตลาดร่วมด้วย จึงเป็นคนละรายการหากเป็น Ticker เดียวกันแต่คนละตลาด

### 3.2 ลบหุ้น

1. กดปุ่ม **ลบ** ที่แถวของหุ้นที่ต้องการลบ
2. ระบบจะแสดงหน้าต่างถามยืนยัน
3. หากต้องการลบ ให้ยืนยันการลบ

หากไม่ต้องการลบ ให้กดยกเลิก รายชื่อหุ้นจะไม่เปลี่ยนแปลง

### 3.3 หลังเพิ่มหรือลบหุ้นแล้วต้องทำอะไรต่อ?

ไม่จำเป็นต้องกด Run workflow ด้วยตนเอง

เมื่อหน้าเว็บบันทึก Watchlist ลง GitHub สำเร็จ การเปลี่ยนแปลงไฟล์ `config/watchlist.json` จะกระตุ้น GitHub Actions ให้ทำงานโดยอัตโนมัติ จากนั้นระบบจะดึงข้อมูลปันผลใหม่และบันทึกผลลง `data/dividends.json`

หลังจากนั้น:

1. รอให้ Workflow ชื่อ **Dividend Alert** ทำงานจนเสร็จและขึ้นสถานะสำเร็จ
2. กลับมาที่เว็บแอป
3. กด **↻ โหลดใหม่** เพื่ออ่านข้อมูลล่าสุด

ปุ่ม **โหลดใหม่** เป็นการโหลดข้อมูลจากไฟล์ JSON ล่าสุด ไม่ได้สั่งให้ระบบไปดึงข้อมูลจาก SET หรือ SmarterDividends ใหม่ด้วยตัวเอง

หากต้องการตรวจสอบการทำงาน ให้เปิดแท็บ Actions ใน GitHub แล้วเลือก Workflow ชื่อ **Dividend Alert** อย่าสับสนกับ Workflow ชื่อ **pages build and deployment** ซึ่งเป็นกระบวนการเผยแพร่หน้าเว็บ

## 4. การใช้งานหลายอุปกรณ์

Watchlist ถูกเก็บไว้ใน GitHub ดังนั้นอุปกรณ์ทุกเครื่องที่เปิดเว็บแอปจะอ่านรายชื่อหุ้นชุดเดียวกัน

ตัวอย่าง:

- เพิ่ม AAPL จากคอมพิวเตอร์ แล้วเปิดเว็บแอปจากแท็บเล็ต ก็จะเห็น AAPL ด้วย
- ลบ PTT จากแท็บเล็ต เมื่อข้อมูลบน GitHub เปลี่ยนแล้ว คอมพิวเตอร์เครื่องอื่นก็จะเห็น Watchlist ที่ไม่มี PTT เช่นกัน

อย่างไรก็ตาม **GitHub Token ไม่ได้แชร์หรือซิงก์ข้ามอุปกรณ์** เพราะ Token ถูกเก็บแยกไว้ใน Local Storage ของแต่ละเบราว์เซอร์

ดังนั้น:

- ทุกอุปกรณ์สามารถเปิดดู Watchlist ได้
- หากต้องการเพิ่มหรือลบหุ้นจากอุปกรณ์ใด อุปกรณ์นั้นต้องเชื่อมต่อ GitHub Token ก่อน
- หากใช้อุปกรณ์ร่วมกับผู้อื่น ควรออกจากระบบหลังใช้งาน

## 5. การแจ้งเตือนผ่าน ntfy

ระบบใช้ ntfy สำหรับส่งการแจ้งเตือนเมื่อหุ้นใน Watchlist มีกำหนดวัน XD ในวันถัดไป

ตัวอย่างข้อมูลในการแจ้งเตือน:

- Ticker
- วัน XD
- วันจ่ายเงินปันผล
- จำนวนเงินปันผลต่อหุ้น

การทำงานตามกำหนดเวลา:

- GitHub Actions ตั้งเวลาให้ตรวจสอบทุกวันตามตารางในไฟล์ `.github/workflows/dividend-alert.yml`
- ตารางปัจจุบันคือเวลา 00:30 UTC หรือประมาณ 07:30 น. ตามเวลาไทย
- หากพบหุ้นที่มีวัน XD เป็นวันพรุ่งนี้ ระบบจะส่งการแจ้งเตือน
- หากไม่มีหุ้นที่ขึ้น XD ในวันพรุ่งนี้ ระบบจะไม่ส่งข้อความแจ้งเตือนตามปกติ

### การทดสอบ ntfy

สามารถเข้า GitHub Actions แล้วเลือก **Dividend Alert > Run workflow** เพื่อทดสอบการทำงานด้วยตนเองได้

การกด Run workflow ด้วยตนเองจะเพิ่มข้อความทดสอบ ntfy ด้วย ไม่จำเป็นต้องมีหุ้นขึ้น XD ในวันถัดไป

การแจ้งเตือนต้องมี GitHub Actions Secret ชื่อ `NTFY_TOPIC` จึงจะส่งได้ ส่วน `NTFY_TOKEN` เป็นค่าเสริมสำหรับกรณีที่ Topic ต้องใช้การยืนยันตัวตน

> การที่ Workflow ทำงานสำเร็จไม่ได้ยืนยันเสมอไปว่าโทรศัพท์หรือแท็บเล็ตได้รับข้อความแล้ว ควรตรวจสอบการสมัคร Topic และการรับข้อความในแอป ntfy ด้วย

## 6. โครงสร้างการทำงานของระบบ

ระบบแบ่งหน้าที่ออกเป็น 4 ส่วนหลัก:

1. **GitHub Pages** ทำหน้าที่เผยแพร่หน้าเว็บให้ผู้ใช้เปิดดูผ่านเบราว์เซอร์
2. **หน้าเว็บ (HTML, CSS, JavaScript)** แสดงข้อมูล อ่าน Watchlist และส่งคำสั่งเพิ่ม/ลบหุ้นไปบันทึกที่ GitHub
3. **GitHub Actions** ทำหน้าที่เรียกโปรแกรม Python ตามกำหนดเวลา หรือเมื่อ Watchlist เปลี่ยนแปลง
4. **Python** ดึงข้อมูลปันผล ประมวลผลวัน XD และวันจ่าย บันทึกผลเป็น JSON และสั่งส่งการแจ้งเตือนผ่าน ntfy เมื่อเข้าเงื่อนไข

### ลำดับการทำงานเมื่อเพิ่มหรือลบหุ้น

1. ผู้ใช้เพิ่มหรือลบหุ้นบนหน้าเว็บ
2. JavaScript ใช้ GitHub Token ส่งคำสั่งบันทึกไฟล์ `config/watchlist.json` ลง GitHub
3. GitHub ตรวจพบการเปลี่ยนแปลงไฟล์ Watchlist
4. GitHub Actions เริ่ม Workflow ชื่อ Dividend Alert โดยอัตโนมัติ
5. Workflow ติดตั้ง Python และไลบรารีที่จำเป็น แล้วเรียก `scripts/update_dividends.py`
6. Python อ่าน Watchlist และดึงข้อมูลปันผลจากแหล่งข้อมูลของแต่ละตลาด
7. Python บันทึกผลลง `data/dividends.json` และตรวจสอบว่ามีหุ้นขึ้น XD ในวันถัดไปหรือไม่
8. หากเข้าเงื่อนไข ระบบจะส่งข้อความผ่าน ntfy
9. GitHub Actions บันทึกไฟล์ข้อมูลที่อัปเดตกลับเข้า Repository
10. หน้าเว็บสามารถอ่านข้อมูลใหม่ได้เมื่อผู้ใช้กดโหลดใหม่ หรือเปิดหน้าเว็บอีกครั้ง

### ลำดับการทำงานประจำวัน

นอกจากการทำงานเมื่อ Watchlist เปลี่ยนแปลงแล้ว GitHub Actions ยังทำงานตามเวลาที่ตั้งไว้ทุกวัน เพื่ออัปเดตข้อมูลปันผลและตรวจสอบ XD ล่วงหน้า

หน้าที่ของไฟล์สำคัญ:

| ไฟล์ | หน้าที่ |
|---|---|

| `js/app.js` | ควบคุมการทำงานของหน้าเว็บ อ่านข้อมูล แสดงตาราง เพิ่ม/ลบหุ้น และบันทึก Watchlist ผ่าน GitHub API |
| `config/watchlist.json` | เก็บรายชื่อหุ้นและตลาดที่ต้องการติดตาม เป็นรายการหลักที่ผู้ใช้แก้ไขผ่านหน้าเว็บ |
| `config/dividend_overrides.json` | เก็บข้อมูลแก้ไขเฉพาะเหตุการณ์ปันผลที่ตรวจสอบแหล่งอ้างอิงแล้ว โดยจับคู่ตามตลาด Ticker และวัน XD อย่างเจาะจง |
| `scripts/update_dividends.py` | โปรแกรม Python สำหรับดึงและประมวลผลข้อมูลปันผล ตรวจสอบ XD และส่งการแจ้งเตือน |
| `data/dividends.json` | เก็บผลข้อมูลปันผลล่าสุดที่ Python ประมวลผลแล้ว เป็นไฟล์ที่หน้าเว็บนำไปแสดง |
| `.github/workflows/dividend-alert.yml` | กำหนดให้ GitHub Actions ทำงานเมื่อ Watchlist เปลี่ยนแปลง ตามเวลาประจำวัน หรือเมื่อสั่ง Run workflow เอง |
| `requirements.txt` | ระบุไลบรารี Python ที่ต้องติดตั้งก่อนรันโปรแกรม |
| `README.md` | คู่มือการใช้งานและอธิบายโครงสร้างของโปรเจกต์ |

## 8. แหล่งข้อมูลปันผล

ระบบใช้แหล่งข้อมูลแยกตามตลาด:

- **หุ้นไทย:** SET Corporate Actions โดยใช้ไลบรารี `settfex` เพื่ออ่านข้อมูล Corporate Actions และคัดเฉพาะรายการ XD
- **หุ้นสหรัฐฯ:** SmarterDividends API โดยอ่านวัน XD จากข้อมูลหุ้น และใช้ข้อมูลปฏิทินปันผลเพื่อเติมจำนวนเงินต่อหุ้นและวันจ่ายเมื่อจับคู่รายการได้

ไฟล์ `config/dividend_overrides.json` ใช้เก็บการแก้ไขข้อมูลเฉพาะเหตุการณ์ที่มีการตรวจสอบแหล่งอ้างอิงเพิ่มเติมแล้ว เช่น ข้อมูลปันผล TSM ADR โดยการแก้ไขจะมีผลเฉพาะตลาด Ticker และวัน XD ที่ตรงกันเท่านั้น

**ข้อควรเข้าใจเกี่ยวกับข้อมูล**

- คำว่า **ยังไม่ประกาศ** หมายถึงแหล่งข้อมูลที่ระบบตรวจสอบยังไม่ให้วัน XD รอบถัดไป ไม่ได้แปลว่าบริษัทจะไม่จ่ายปันผล
- หากแหล่งข้อมูลขัดข้องหรือดึงข้อมูลหุ้นบางตัวไม่สำเร็จ ระบบอาจแสดงสถานะดึงข้อมูลไม่สำเร็จ และอาจเก็บค่าบางส่วนจากข้อมูลรอบก่อนหน้าไว้
- ข้อมูลจากผู้ให้บริการภายนอกอาจล่าช้า ไม่ครบถ้วน หรือมีการแก้ไขภายหลัง
- ควรตรวจสอบประกาศจากบริษัท ตลาดหลักทรัพย์ หรือแหล่งข้อมูลทางการก่อนใช้ประกอบการตัดสินใจลงทุน

## 9. การแก้ปัญหาเบื้องต้น

**เพิ่มหรือลบหุ้นไม่ได้**

- ตรวจสอบว่าเชื่อมต่อ GitHub แล้วหรือยัง
- ตรวจสอบว่า Token ยังไม่หมดอายุหรือถูกเพิกถอน
- ตรวจสอบว่า Token ให้สิทธิ์ Contents: Read and write กับ Repository `dividend-alert`
- หากยังไม่ได้ ให้สร้าง Token ใหม่และเชื่อมต่ออีกครั้ง

**เพิ่มหุ้นแล้วหน้าเว็บยังไม่แสดงข้อมูลใหม่**

- ตรวจสอบว่า Watchlist บันทึกลง GitHub สำเร็จแล้ว
- เปิด GitHub Actions แล้วดู Workflow ชื่อ Dividend Alert ว่าทำงานเสร็จหรือยัง
- เมื่อ Workflow สำเร็จ ให้กลับมากดปุ่ม **↻ โหลดใหม่**
- หาก Workflow ล้มเหลว ให้เปิดรายละเอียด Run เพื่อดูข้อความผิดพลาด

**หน้าเว็บแสดงข้อมูลเก่า**

- กดปุ่ม **↻ โหลดใหม่**
- หากเพิ่งมีการแก้ไขโค้ดหน้าเว็บ อาจต้องรอ GitHub Pages เผยแพร่เวอร์ชันใหม่ แล้วรีเฟรชเบราว์เซอร์อีกครั้ง

**ไม่ได้รับการแจ้งเตือน ntfy**

- ตรวจสอบว่า GitHub Actions Secret `NTFY_TOPIC` ถูกตั้งค่าแล้ว
- ตรวจสอบว่าอุปกรณ์สมัคร Topic เดียวกันในแอป ntfy
- ตรวจสอบว่าอนุญาตการแจ้งเตือนของแอป ntfy ในระบบปฏิบัติการแล้ว
- ดู Log ของ Workflow ว่ามีข้อความส่งสำเร็จ ข้ามการส่ง หรือเกิดข้อผิดพลาดหรือไม่

## 10. ข้อจำกัดและคำเตือน

โปรเจกต์นี้เป็นเครื่องมือช่วยติดตามกำหนดการปันผล ไม่ใช่แหล่งยืนยันข้อมูลทางการ และไม่ใช่คำแนะนำในการลงทุน

การแสดงวัน XD หรือจำนวนเงินปันผลขึ้นอยู่กับข้อมูลจากแหล่งภายนอก การประกาศของบริษัทอาจเปลี่ยนแปลงได้ ผู้ใช้ควรตรวจสอบข้อมูลกับแหล่งทางการก่อนตัดสินใจลงทุนทุกครั้ง
